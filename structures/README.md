# structures

Structure files loaded by the ChlamAtlas Mol* viewer.

| Folder | Contents |
|---|---|
| `CTDUW3/`, `CTL2/` | Experimental structures from the [RCSB PDB](https://www.rcsb.org), named by PDB ID |
| `af3/` | AlphaFold 3 predictions, one folder per locus tag (`<LOCUS_TAG>/<LOCUS_TAG>_af3.cif`) |

AlphaFold 3 predictions are provided under the [AlphaFold 3 Output Terms of Use](https://github.com/google-deepmind/alphafold3/blob/main/OUTPUT_TERMS_OF_USE.md). The site loads these files by URL, so file paths must not change.
