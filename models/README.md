# models

AlphaFold Database (v4) models in mmCIF format for *C. trachomatis* D/UW-3, named by UniProt accession (`AF-<accession>-F1-model_v4.cif`). The ChlamAtlas Mol* viewer loads these files directly.

Source: [AlphaFold Protein Structure Database](https://alphafold.ebi.ac.uk), CC BY 4.0. The site loads these files by URL, so file paths must not change.
